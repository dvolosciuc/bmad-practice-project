Direction 1 — "Signal" · Analysis

Strengths

  • Maximum loss-aversion impact — headline dominates first paint
  • Single column → frictionless mobile scroll
  • Teal accent = forward momentum, not alarm
  • Transparent → solid header on scroll (trust signal)
  • Closest to PRD vision

Trade-offs

  • Minimal visual variety between sections
  • Desktop may feel sparse at max-width 720px

Direction 2 — "Ledger" · Analysis

Strengths

  • Data-dense; appeals to analytical users (Natalia, Andrei)

  • Table layout ideal for operator tariff comparison

Trade-offs

  • Two-column hero breaks on small mobile
  • Less emotional impact — feels like a spreadsheet
  • Loses loss-aversion punch with blue accent

Direction 3 — "Ember" · Analysis

Strengths

  • Amber/gold feels premium and warm
  • Strong vertical rhythm with dividers
  • Section tags create clear visual hierarchy

Trade-offs

  • Amber associates with caution/warning, not EV positivity
  • Warm tone may feel less "electric/modern"
  • Lower contrast on dark brown background

Direction 4 — "Minimal (Light)" · Analysis

Strengths

  • High readability; excellent for older demographics
  • Feels official / trustworthy (government-adjacent)
  • Strong contrast by default

Trade-offs

  • Light mode contradicts PRD "dark/teal design" spec
  • Less emotionally charged — loses urgency impact
  • Doesn't differentiate from standard info sites

Direction 5 — "Grid" · Analysis

Strengths

  • Editorial / magazine feel — strong visual hierarchy
  • Sidebar stats make data immediately scannable
  • Bold grid lines create authoritative structure

Trade-offs

  • Two-column grid collapses awkwardly on mobile
  • All-caps headers feel aggressive at scale
  • More complex layout = more responsive work

Direction 6 — "Flow" · Analysis

Strengths

  • Gradient headline is visually striking
  • Card grid clearly segments the four data pillars
  • App-store aesthetic feels modern and shareable

Trade-offs

  • Gradient text reduces legibility on some screens
  • Purple in gradient shifts brand away from EV/teal identity
  • Card-grid fragments the single-scroll emotional arc
  • Hero CTA buttons add friction before the user sees anything
